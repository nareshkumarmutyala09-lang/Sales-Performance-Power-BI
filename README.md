# Hospital Billing & Appointment Dashboard – Power BI

## Project Overview
This Power BI dashboard provides an overview of hospital appointments,
billing, doctors, departments, cities and appointment status.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel

## Dashboard Features
- Total Appointments
- Appointment Status Analysis
- Department Analysis
- City-wise Analysis
- Doctor-wise Data
- Billing Analysis
- Interactive Filters

## Key Visualizations
- KPI Cards
- Bar Chart
- Pie Chart
- Date Analysis
- Slicers
- Interactive Filters
